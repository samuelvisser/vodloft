# VodLoft user guide

VodLoft stores a local library from web Sources and can deliver it to podcast players and media servers.

Start with [Installation](Installation.md) and [First-run setup](First-Run-Setup.md), then [the library](Shows-and-Library.md). Use [Local Media Profiles](Local-Media-Profiles.md) to choose files and [Collection Download Profiles](Download-Profiles.md) to automate acquisition.

[RSS feeds](Podcast-RSS-Feeds.md), [media servers](Media-Server-Integrations.md), and [local accounts](Accounts-and-Requests.md) describe sharing and listening. [Sources](Sources-and-Updates.md) covers upstream accounts and updates. [Backups and upgrades](Backups-and-Upgrades.md) explains preserving an existing WireLoft installation.
