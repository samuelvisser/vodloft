# The Daily Wire

The Daily Wire is one of VodLoft's bundled Sources. It provides Domain discovery, URL resolution, Collection enumeration, search, acquisition, and upstream playback for supported media.

Add an account in **Management → Source connections** and use its authentication controls or declared token field. Follow the displayed challenge when interactive sign-in is required. Entitlement is determined by the upstream account.

Paste a supported show, episode, Movie, or clip URL in **Discover**. Review and import the normalized item. Shows/seasons become Collections and membership groups; Movie Extras retain Movie parent relationships. Select the same account reference for Collection automation and feed preparation.

Output quality, audio-only renditions, languages, and delivery are configured through Domain Local Media Profiles, not provider-specific screens. Changing or updating The Daily Wire adapter preserves those profiles.

See [Sources and updates](Sources-and-Updates.md) for account scoping, runtime updates, and failures requiring reauthentication.
