# First-run setup

Open VodLoft, sign in if an administrator password is configured, and choose **Open VodLoft** on the welcome screen. You can use public yt-dlp-supported URLs immediately; a Source account is optional until a provider requires authentication.

In **Discover**, paste a URL and review the preview before importing. A preview shows the Source, Domain, media type, and available entries. If several Sources or account connections can handle it, choose the one you intend to use.

Initial Local Media Profiles are provided for YouTube and The Daily Wire. In **Management**, edit them or create a profile for another Domain. An audio profile using M4A/AAC or MP3 is suitable for audio podcast feeds; MP4 is suitable for video feeds.

Add Source connections only for upstream credentials. Local user accounts and Plex/Jellyfin/Audiobookshelf identities are configured separately. See [Accounts and requests](Accounts-and-Requests.md).
